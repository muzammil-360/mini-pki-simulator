# Mini PKI Simulator

Cryptography and Security microproject - Shaikh Mujammil (39), Swayam Mahulkar (54)

## Files
- index.html - page structure (semantic tags, form, tables, media)
- style.css  - styling (box model, flexbox, media queries)
- script.js  - logic (DOM, events, validation, RSA via Web Crypto)
- media/     - pki-demo.mp4 (narrated slides) and pki-explained.mp3 (audio)

## Run locally
Open index.html in Chrome or Edge. In VS Code you can also use the Live Server extension.

## Deploy (GitHub Pages)
Upload all files and the media folder to a public repo, then Settings > Pages > Deploy from branch > main > /(root).
